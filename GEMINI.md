# GEMINI.md

Instructions for Gemini CLI working on Commerce Lab (same as AGENTS.md).

1. **Read `CLAUDE.md` first.** Despite its name it is the project briefing for every AI tool: what is being built,
   the non-negotiables (mobile first, static only, correct facts), how the site is put together, and the current status.
2. **Writing or editing a lesson:** follow `docs/LESSON-AUTHORING.md`.
3. **Checking for compliance updates** ("run the compliance check", "refresh What's New"):
   follow `docs/COMPLIANCE-CHECK.md`.
4. Run `npm test` before you finish. Commit and push only when the user asks.
